## 🎯 Features

- **Browse Disk Images**: Open and explore AKAI S950 .IMG files directly on your Mac.
- **Edit Samples**: Modify S9 and P9 samples with an intuitive interface.
- **Edit Programs**: Change program settings and parameters for your sampler.
- **Native macOS App**: Built with SwiftUI for a smooth, responsive experience.
- **Ableton Live Integration**: Compatible with Ableton Live workflows for modern music production.
- **No Programming Required**: Simple point-and-click interface for all users.

## 🖥️ System Requirements

- **Operating System**: macOS 11.0 (Big Sur) or later
- **Processor**: Apple Silicon or Intel Core processor
- **Memory**: 4 GB RAM minimum
- **Storage**: 50 MB available space
- **Display**: 1280x800 resolution or higher

## 📖 How to Use

1. **Launch the App**: Double-click the AKAI-Image-Manager icon.
2. **Open a Disk Image**: Click "Open" and select your .IMG file.
3. **Browse Samples**: Navigate through the samples and programs in the disk image.
4. **Edit Content**: Click on any sample or program to edit its properties.
5. **Save Changes**: Export your edited files back to the disk image or save them separately.

## 🛠️ Troubleshooting

- **App Won't Open**: Make sure you're running macOS 11.0 or later.
- **Can't Open .IMG File**: Verify the file is a valid AKAI S950 disk image.
- **Performance Issues**: Close other apps and restart AKAI-Image-Manager.
