AKAI IMAGE MANAGER — THIRD-PARTY TOOLS AND SOURCES
===================================================

No third-party executable or library is bundled inside AKAI Image Manager.
The application uses Apple system frameworks and launches separately installed
tools only when their features are requested. One sanitized, audio-free Ableton
Live user-preset template is included as application data for Drum Rack export;
see section 4.

3. User-selected audio editor
-----------------------------

Purpose:
  Optional application used only by the direct S950 sample-editing
  workflow. It must be able to open and save PCM WAV files.

Terms:
  No audio editor is included or required for the rest of AKAI Image Manager.
  Users choose and license their preferred editor independently. AKAI Image
  Manager does not link to, redistribute, or depend on a particular editor.


4. Ableton Live user-preset template
------------------------------------

Purpose:
  Used as the structural basis for S950-to-Ableton Drum Rack export. The app
  creates one Ableton Sampler device per exported S950 keygroup.

Provenance:
  Created by the project author in Ableton Live 12.4.3, then sanitized for this
  application. Personal paths, usernames, audio samples, browser identifiers
  and source-preset names were removed. The bundled ADG contains device state
  only and is not the Ableton application or a sound library.

Requirement and terms:
  Ableton Live is proprietary software and is not included. Users must obtain
  and license it from Ableton to open the generated ADG files. Ableton is not
  needed for AKAI Image Manager's other features.

Official product site:
  https://www.ableton.com/live/


5. Apple system components
--------------------------

AKAI Image Manager uses SwiftUI, AppKit, AVFoundation, UniformTypeIdentifiers
and CryptoKit supplied with macOS. Rosetta is an Apple system component needed
only to run the Intel AKAI Util binary on Apple-silicon Macs.

Rosetta information:
  https://support.apple.com/102527

Gatekeeper and unnotarized-app guidance:
  https://support.apple.com/102445
